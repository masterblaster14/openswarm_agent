# Add discount codes to checkout

Support percentage and fixed-amount discount codes at checkout. Codes have expiry dates and usage limits. Apply before tax. New endpoint POST /checkout/apply-discount.

_Swarm run `run_93c6f079` · 15848 tokens · $0.0314_

## Decisions
- **discount-type-enum** — Discount codes store type as enum: PERCENTAGE | FIXED_AMOUNT, not string or boolean. (95%)
- **discount-application-order** — Apply discount codes to subtotal before tax calculation; tax is computed on (subtotal - discount). (98%)
- **code-validation-atomicity** — Validate code existence, expiry, usage limit, and applicability in a single database query with row-level locking to prevent race conditions on usage_count. (92%)
- **endpoint-request-schema** — POST /checkout/apply-discount accepts {code: string, checkout_id: uuid} and returns {discount_amount: decimal, discount_type: enum, new_total: decimal, error?: string}. (90%)
- **usage-limit-tracking** — Store usage_limit (nullable integer) and usage_count (integer, default 0) on discount_codes table; increment usage_count only on successful checkout completion, not on apply-discount call. (88%)
