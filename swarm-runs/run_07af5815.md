# Add discount codes to checkout

Support percentage and fixed-amount discount codes at checkout. Codes have expiry dates and usage limits. Apply before tax. New endpoint POST /checkout/apply-discount.

_Swarm run `run_07af5815` · 14812 tokens · $0.0262_

## Decisions
- **discount-type-enum** — Discount codes store type as enum: PERCENTAGE | FIXED_AMOUNT, not string or boolean. (95%)
- **discount-application-order** — Apply discount codes to subtotal before tax calculation; tax is computed on (subtotal - discount). (98%)
- **usage-limit-enforcement** — Track usage_count (integer) and max_uses (nullable integer); reject code if usage_count >= max_uses. Null max_uses = unlimited. (92%)
- **expiry-validation-utc** — Store expiry_date as UTC timestamp; reject code if current_time > expiry_date. Null expiry_date = no expiration. (97%)
- **apply-discount-endpoint-response** — POST /checkout/apply-discount returns {code, discount_type, discount_value, applied_amount_cents, new_subtotal_cents, error?} on success; 400 with {error, reason} on invalid/expired/exhausted code. (90%)
